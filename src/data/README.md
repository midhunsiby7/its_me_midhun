# Astronomical star data

`constellationStars.json` is a curated set of 88 principal naked-eye
stars from the requested constellations. Coordinates, apparent visual
magnitude, colour index, spectral type, and distance are taken from the
HYG Stellar Database v4.4 (J2000 right ascension and declination).

Source: https://codeberg.org/astronexus/hyg

The portfolio uses the catalog coordinates in a single Hammer-Aitoff
projection. Stellar distance is retained as reference data only; it does
not alter the projected position or apparent brightness.
